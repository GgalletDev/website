# Politique de Confidentialité — SmashDice

Dernière mise à jour : 25 mai 2026

Bienvenue dans SmashDice, un jeu développé par GG Games Labs.

Cette Politique de Confidentialité explique quelles données peuvent être collectées lorsque vous utilisez le jeu, comment elles sont utilisées, et quels sont vos droits.

---

## 1. Données collectées

SmashDice collecte uniquement les données nécessaires au fonctionnement du jeu.

### Données de jeu

Le jeu peut stocker :

- le pseudonyme choisi par le joueur ;
- les 10 meilleurs scores du joueur.

Ces données sont enregistrées via Google Firebase Firestore afin de permettre la sauvegarde et le fonctionnement du classement.

### Authentification anonyme

SmashDice utilise Firebase Anonymous Authentication afin de créer un identifiant technique anonyme permettant de sauvegarder les données du joueur.

Aucune inscription ni création de compte avec email n’est requise.

### Publicités

Le jeu utilise Google AdMob pour afficher :

- des publicités interstitielles ;
- des publicités récompensées (rewarded ads).

AdMob peut collecter certaines données techniques et publicitaires conformément à ses propres politiques de confidentialité.

### Consentement publicitaire

Le jeu utilise Google UMP (User Messaging Platform) afin de gérer le consentement des utilisateurs concernant les publicités personnalisées, conformément aux réglementations applicables, notamment le RGPD en Europe.

---

## 2. Utilisation des données

Les données collectées sont utilisées uniquement pour :

- sauvegarder la progression et les meilleurs scores ;
- assurer le bon fonctionnement du jeu ;
- afficher des publicités ;
- améliorer la stabilité et l’expérience utilisateur.

---

## 3. Partage des données

Les données peuvent être traitées par les services tiers suivants :

- Google Firebase
- Google AdMob
- Google UMP

Ces services peuvent traiter certaines données conformément à leurs propres politiques de confidentialité.

---

## 4. Conservation des données

Les données de jeu sont conservées tant qu’elles sont nécessaires au fonctionnement du service.

Vous pouvez demander la suppression de vos données à tout moment :
Vous pouvez supprimer votre compte et les données associées directement depuis les paramètres du jeu, comme expliqué sur notre page [Supprimer mon compte et mes données](/fr/games/smash-dice/delete-data).

---

## 5. Droits des utilisateurs

Conformément aux lois applicables, notamment le RGPD, vous pouvez demander :

- l’accès à vos données ;
- la correction de vos données ;
- la suppression de vos données.

Pour toute demande, vous pouvez nous contacter à :

contact@gggameslabs.com

Ou suivre les étapes sur notre page [Supprimer mon compte et mes données](/fr/games/smash-dice/delete-data).

---

## 6. Enfants

SmashDice est un jeu destiné à tout public.

Le jeu ne collecte pas volontairement d’informations personnelles sensibles concernant les enfants.
